LLM Decode 速度估算器

自迴歸生成的每個 token 都要把權重讀過一遍，所以 decode 階段受記憶體頻寬限制，與算力幾乎無關。 推導與驗證方法見 推論速度怎麼估。 

單卡：   tok/s = 頻寬 × MBU / 每 token 讀取位元組
offload：tok/s = 1 / ( GPU端位元組/(GPU頻寬×MBU) + CPU端位元組/(DRAM頻寬×MBU) )
每 token 讀取位元組 = 激活參數 × 每參數位元組 + KV cache 讀取

這個估算沒有涵蓋：

  • 推測解碼（speculative decoding）可在頻寬不變下把有效速度提高一到三倍
  • MoE offload 的專家存取是隨機而非循序的，實際 DRAM 頻寬會低於規格值，建議把結果再打七到八折
  • prefill 時間（首個 token 的延遲）由算力決定，不在此公式範圍
  • 沒有硬體原生支援的量化格式，每次運算都要 dequant，MBU 會明顯下降
