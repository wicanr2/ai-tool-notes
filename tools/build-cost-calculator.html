本地 LLM 建置成本估算器

從模型參數推出硬體需求，再換算建置成本與「自建 vs 租用」的回本點。 推導與價格來源見 要跑這些模型最少需要多少硬體。 

顯存需求 = 參數量 × 每參數位元組 + KV cache
KV cache = 2 × 全域注意力層數 × (kv_heads × head_dim) × KV精度 × context × 併發數
GPU 張數 = ceil( 需放進顯存的部分 / 單卡顯存 )
系統記憶體 = offload 的權重 × 1.25（作業系統、頁面對齊、pinned 額外開銷）
建置成本 = GPU單價×張數 + RAM每GB×容量 + 平台 + 儲存
回本月數 = 自建總價 / (雲端每小時 × 730 × 利用率)
